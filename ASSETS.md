# Assets

**Art direction:** High-contrast 2.5D tactical vector language for a mobile CQB command console. Use graphite and olive surfaces, cyan tactical overlays for the player, signal red for the hostile, amber wood for half cover and dark steel with orange hazard bands for full cover. Shapes are clean and readable at smartphone scale, with subtle scanlines and depth shadows.
